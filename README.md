This repository contains the index.py which is a file containing all of the separate code files in one.
It is made up of the following files:
parser.py
interpreter.py
lexer.py
values.py
errors.py
main.py

However, you can look through each of these files separately.
test_file.cool contains code written in my programming language and is the file that is interpreted when the index file is run.

Additionally, the grammar.txt file outlines the general structure for my language but doesn't add anything to the code as it was just for planning.

NOTE: There are 3 indexes and each is an updated version of the other as I developed my programming language iteratively by getting feedback from a focus group each week and improving it.
For the most updated version check out index3.

To access the syntax for my programming language go to my profile where you will see a repository called "My-Programming-Language".

Thank you for checking out my programming language!
